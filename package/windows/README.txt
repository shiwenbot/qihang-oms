启航电商 OMS Windows 桌面版

双击 QihangOMS-Setup-*.exe，安装到纯英文路径（例如 D:\QihangOMS）。
Windows 可能提示“未知发行者”，点“更多信息”再“仍要运行”。升级覆盖程序文件，不会删除 runtime\mysql\data（数据库）和 config。不要放桌面、微信下载目录或带中文的文件夹。

打开桌面“启航电商 OMS”（或安装目录 QihangOMS.exe）即启动全部服务，并在窗口内打开系统；关闭窗口即停止全部服务。
首次启动会在本目录创建全新的本机数据库，请等窗口显示“运行中”后再登录。
窗口内地址默认 http://127.0.0.1:8086，初始账号 admin，密码 admin；首次登录后请修改密码。登录页不需要验证码。若 8086/3306/6379/18080 已被占用，启动时会自动改用空闲端口。
电子面单打印仍需安装各平台打印组件（菜鸟/京东/拼多多/抖音/快手）。若提示缺少 WebView2，安装 Microsoft Edge WebView2 运行时，或点“浏览器打开”。

超级管理员在“市场情报 - 采集配置”中扫码连接采集账号。凭据只用 Windows DPAPI 加密保存在当前 Windows 用户目录，不在安装包或数据库中。

卸载：安装目录 Uninstall-QihangOMS.exe，或系统“应用和功能”。默认保留数据库；勾选删除数据才会清库。

市场情报只采集公开内容。登录凭据不要发给他人；需要让朋友使用时，由朋友在自己的电脑上扫码连接自己的账号。
