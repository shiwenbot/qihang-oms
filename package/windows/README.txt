启航电商 OMS Windows 免安装版

1. 解压到纯英文路径（例如 D:\QihangOMS），不要放桌面、微信下载目录或带中文的文件夹。
2. 双击 Start-OMS.bat 启动。也可以点“启动OMS.bat”。首次启动会在本目录创建全新的本机数据库，请等黑窗口出现 Started 后再登录。
3. 浏览器打开启动窗口打印的地址（默认 http://127.0.0.1:8086），初始账号 admin，密码 admin；首次登录后请修改密码。登录页不需要验证码。若 8086/3306/6379/18080 已被占用，启动时会自动改用空闲端口并打印出来。
4. 超级管理员在“市场情报 - 采集配置”中扫码连接采集账号。凭据只用 Windows DPAPI 加密保存在当前 Windows 用户目录，不在安装包或数据库中。
5. 退出前双击 Stop-OMS.bat（或“停止OMS.bat”）。停止程序只处理本安装目录启动并记录的进程。

市场情报只采集公开内容。登录凭据不要发给他人；需要让朋友使用时，由朋友在自己的电脑上扫码连接自己的账号。
